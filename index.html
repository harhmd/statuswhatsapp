Install on Phone & Live Usage

Progressive Web App (PWA) & File Access

1. Install as a Phone App (Android & iOS)

  • Android (Chrome/Edge): Tap the Install App button at the top or tap browser menu (⋮) → Add to Home screen / Install app.
  • iPhone / iPad (Safari): Tap the Share icon () at the bottom → scroll down and tap Add to Home Screen.

2. Load Live WhatsApp Statuses

  1. Open WhatsApp on your phone so new statuses cache to storage.
  2. Open WA Status Saver and tap Open .Statuses Folder.
  3. In your file picker, tap menu (⋮) → Show hidden files, then browse to:
    Android > media > com.whatsapp > WhatsApp > Media > .Statuses
  4. Tap Use this folder → Allow. All live statuses load instantly!
